# Letrix kelime verisi / word data

Letrix uygulamasının cevap ve anlam listeleri. Bu dosyalar açık lisanslı kaynaklardan türetilmiştir ve aynı lisanslarla paylaşılır.

The answer and meaning lists of the Letrix app, derived from openly licensed sources and shared under the same licences.

| Dosya / File | Kaynak / Source | Lisans / Licence |
|---|---|---|
| `tr/answers_*.txt`, `en/answers_*.txt` | Sözlük ile kesiştirilen sıklık listeleri: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `tr/defs_*.txt` | [Vikisözlük](https://tr.wiktionary.org/), [kaikki.org](https://kaikki.org/trwiktionary/) çıkarımı | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| `en/defs_*.txt` | [Open English WordNet 2025](https://github.com/globalwordnet/english-wordnet) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

Kelimeleri doğrulamak için kullanılan sözlükler: Türkçe [Zemberek-NLP](https://github.com/ahmetaa/zemberek-nlp) (Apache 2.0), İngilizce ENABLE (kamu malı).

**Yapılan değişiklikler / Changes made:** büyük harfe çevirme, 4–7 harf dışındaki kelimelerin atılması, tanımların kısaltılıp seçilmesi. Ayrıntılar: [SOURCES.md](SOURCES.md).
